# ヘルスケアから運動を取り込む（iPhone のショートカット）

Runkeeper などがヘルスケアに書き込んだ「今日の運動の消費カロリー・距離」を、iPhone の **ショートカット** アプリで集めて Power に取り込みます。

> ショートカットの操作名は iOS のバージョンで少し違うことがあります。見つからない項目があれば、近い名前のものを選んでください。

## しくみ

1. Power の記録画面「運動」で **① ショートカットを実行** を押す
2. ショートカットが今日の値を集めて、次のような 1 行をコピーする
   ```
   power kind=run kcal=352.4 km=5.21
   ```
3. Power に戻り（画面左上の「◀ Power」）、**② コピーした内容を取り込む** を押す → 内容を確認して **この内容で保存**

- データはスマホの中だけでやり取りします（インターネットには送りません）。
- 同じ日の同じ種目は上書きされるので、何度取り込んでも二重になりません。
- ホーム画面に追加した Power は Safari とは別の保存場所を使うため、「URL を開く」方式ではなく、コピー＆取り込みの方式にしています。

## 準備：Runkeeper → ヘルスケア

1. Runkeeper のアプリで、ヘルスケアとの連携をオンにする（設定 → アプリ連携 → ヘルスケア など）
2. iPhone の **設定 → ヘルスケア → データアクセスとデバイス → Runkeeper** で、「アクティブエネルギー」「ウォーキング＋ランニングの距離」「ワークアウト」の書き込みを許可する
3. ヘルスケアのアプリで **アクティブエネルギー** を開き、「データソースとアクセス」に Runkeeper があることを確認する

## ショートカットの作り方

ショートカットアプリ → 右上の **＋** → 名前を **`Power取り込み`**（この名前で Power から呼び出します）にして、次のアクションを順に追加します。

### 1. 今日の消費カロリー（Runkeeper の分）

1. **ヘルスケアサンプルを検索** を追加
   - 種類：**アクティブエネルギー**
   - 「フィルタを追加」で：**開始日** が **今日** である
   - 「フィルタを追加」で：**ソース** が **Runkeeper** である（ここで Runkeeper の分だけに絞ります）
2. **統計を計算** を追加 → **合計**、対象は 1. の「ヘルスケアサンプル」
   - 結果の変数名を「消費」にしておくと分かりやすいです（変数をタップ → 名前を変更）

### 2. 今日の距離（任意）

1. **ヘルスケアサンプルを検索**：種類 **ウォーキング＋ランニングの距離**、開始日が今日、ソースが Runkeeper
2. **統計を計算** → **合計**（変数名「距離」）
   - 単位がマイルになっている場合は、ヘルスケアの距離の単位をキロメートルにしてください

### 3. コピーして知らせる

1. **テキスト** を追加し、次のように入力（`[消費]`・`[距離]` は上の変数を差し込みます）
   ```
   power kind=run kcal=[消費] km=[距離]
   ```
   - 距離を使わない場合は `power kind=run kcal=[消費]` だけで構いません
2. **クリップボードにコピー**（対象はテキスト）
3. **通知を表示**：「コピーしました。Power に戻って ② を押してください」

### はじめて実行するとき

ヘルスケアの読み取りを許可するか聞かれるので、「アクティブエネルギー」「距離」を許可してください。

## 書き方の決まり（参考）

1 行に 1 件、`power` で始めて `名前=値` をスペースで区切ります。

| 名前 | 内容 | 省略したとき |
|---|---|---|
| `kcal` | 消費カロリー（必須）。「352.4 kcal」のように単位が付いていても読めます | — |
| `km` | 距離 | なし |
| `min` | 時間（分） | なし |
| `kind` | `run`（ランニング）/ `walk` / `strength`（筋トレ）/ `cycle` / `other` | `run` |
| `date` | 日付（`2026-11-23` または `2026/11/23`） | 今日 |
| `name` | 記録の名前（スペースなし） | 「ランニング（ヘルスケア）」など |

複数の行を入れると、まとめて取り込めます（例：ランニングとウォーキング）。

## うまくいかないとき

- **「運動の記録がありませんでした」と出る**：Runkeeper がアクティブエネルギーを書き込んでいない可能性があります。ヘルスケアのアプリで、今日のアクティブエネルギーに Runkeeper の値があるか確認してください。なければ、Runkeeper に表示された消費カロリーを Power の「運動」に手で入力してください。
- **② を押しても何も起きない／許可を求められる**：iPhone が「ペースト」の許可を求めることがあります。「ペースト」を押してください。だめなときは「手で貼り付ける」から貼り付けられます。
- **筋トレ**：アプリで記録していなければ、Power の「運動」で種目を「筋トレ」、時間を入れて追加すると、消費カロリーの目安を自動で計算します。
