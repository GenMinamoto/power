# Power

筋肉を増やしながら体脂肪を落とすための記録アプリです。体重・体脂肪率・食事を記録し、グラフで推移を確認します。
PC 版とスマホ版（iPhone）があります。どちらも記録データは端末の中にだけ保存し、外部には送信しません。費用はかかりません。

- 要件定義書：[docs/requirements.md](docs/requirements.md)
- 基本設計書：[docs/basic-design.md](docs/basic-design.md)
- 詳細設計書：[docs/detailed-design.md](docs/detailed-design.md)

## 使い方

必要なもの：[Node.js](https://nodejs.org/) 22.13 以上（推奨 24）

1. `start.bat` をダブルクリックします。
   - 初回は必要なファイルを自動で準備します（数分かかることがあります）。
   - プログラムが更新されていれば（`git pull` 後など）、自動でビルドし直してから起動します。
2. ブラウザで `http://localhost:3000` が開きます。
3. 終了するときは、黒いウィンドウを閉じます。

## スマホ版（iPhone）

公開先：`https://genminamoto.github.io/power/`（GitHub Pages）

- 公開されているのは**アプリのプログラムだけ**です。記録データはスマホのブラウザの中（Power 専用の保存場所）にだけ保存され、どこにも送信しません。
- 外部への通信はブラウザの設定（Content Security Policy）で禁止しています。
- 一度開けば、電波がなくても使えます。
- PC 版とスマホ版のデータは別々です（同期はしません）。

### はじめて使うとき

1. iPhone の **Safari** で公開先の URL を開きます。
2. 共有ボタン → **「ホーム画面に追加」** を押します。以後はホーム画面のアイコンから開きます。
   - ホーム画面に追加しないと、しばらく開かなかったときに Safari がデータを消すことがあります。
3. PC 版のデータを移すとき：PC 版でエクスポート → そのファイルを iCloud Drive などでスマホに送る → スマホ版の「目標・設定」→「インポート…」で選ぶ。

### 運動・ヘルスケア

- 記録画面の「運動」でランニング・筋トレなどを記録します。消費カロリーを空欄にすると、体重と時間・距離から目安を計算します。
- 運動した日は、目標カロリーに「運動の消費 ×（1 − 減量ペース）」を上乗せします（炭水化物として）。そのため「目標・設定」の活動レベルは **ほぼ運動しない（×1.2）** にします。
- Runkeeper などがヘルスケアに書き込んだ消費カロリーは、iPhone のショートカット経由で取り込めます：[docs/health-shortcut.md](docs/health-shortcut.md)

### データの守り方

- 開くたびに 1 日 1 回、スマホの中に自動でバックアップします（30日分）。「目標・設定」→「データ」→「スマホ内のバックアップから戻す」で戻せます。
- スマホの故障・紛失に備えて、**ときどき「エクスポート」→「ファイルに保存」で iCloud Drive などに保存**してください。7 日以上エクスポートしていないと、ホームでお知らせします。
- GitHub のアカウントには 2 段階認証を設定してください（プログラムの書き換えを防ぐため）。

### 公開のしくみ

`main` に push すると、GitHub Actions（[.github/workflows/pages.yml](.github/workflows/pages.yml)）がテスト → ビルド → 公開を自動で行います。
初回だけ、GitHub のリポジトリの Settings → Pages → Source を **GitHub Actions** にする必要があります。

## データとバックアップ（PC 版）

| 場所 | 内容 |
|---|---|
| `data/power.db` | 記録データ本体 |
| `data/backups/power-YYYYMMDD.db` | 自動バックアップ（起動時に 1 日 1 回作成、30 日分を保持） |

`data/` フォルダは Git の管理対象外です。PC を移行するときは `data/` フォルダごとコピーしてください。

### エクスポート / インポート

「目標・設定」画面の「データ」から操作します。

- **エクスポート**：全データ（体組成・食事・マイ食品・目標・プロフィール）を 1 つの JSON ファイルに書き出します。PC の移行や控えに使えます。
- **インポート**：エクスポートしたファイルを選ぶと、現在のデータをすべてその内容に置き換えます。読み込む前に `data/backups/` へ自動でバックアップ（`…-pre-import.db`）を作ります。ファイルに問題があるときは何も変更しません。

### バックアップから戻す方法

1. アプリを終了します（黒いウィンドウを閉じる）。
2. `data/power.db`、`data/power.db-wal`、`data/power.db-shm` を別の場所に移動します（念のため削除せず残しておきます）。
3. 戻したい日の `data/backups/power-YYYYMMDD.db` を `data/power.db` という名前でコピーします。
4. `start.bat` で起動します。

## 開発

```sh
npm install
npm run dev        # 開発サーバー（画面 http://localhost:5173 、API :3000）
npm test           # 自動テスト（計算・API）
npm run test:e2e   # 画面の自動テスト（ビルド後、Microsoft Edge を自動操作。保存先は一時フォルダ）
npm run typecheck  # 型チェック
npm run build      # ビルド（dist/）
npm start          # ビルド済みを起動

npm run build:mobile      # スマホ版のビルド（dist/mobile/）
npm run test:e2e:mobile   # スマホ版の画面テスト（iPhone の画面サイズ。Edge と WebKit で実行）
                          # 初回は npx playwright install webkit が必要
```

スマホ版は PC 版のサーバーの処理（`src/server/routes`・`repositories`）をそのままブラウザの中で動かしています。
データベースは sql.js（ブラウザで動く SQLite）で、変更のたびに IndexedDB へ保存します（`src/mobile/`）。
